# Hangman Game - CodeAlpha Internship

This project is Task 1 of my Python Programming Internship at CodeAlpha.

The Hangman game is a simple text-based game written in Python.
The program randomly selects a word and the user guesses the word letter by letter.

---

## Technologies Used
- Python
- VS Code

---

## How to Run the Program
1. Install Python on your system
2. Open the project folder in VS Code
3. Open the terminal
4. Run the command:
   python hangman.py

---

## How the Game Works
- The game displays blanks (_) for the hidden word
- The user enters one letter at a time
- Correct guesses reveal the letters
- Wrong guesses reduce the number of attempts
- The player wins by guessing all letters correctly
